# Acceptance checklist

Status of each PRD §15 criterion. **Pass** means an automated test exercises the behavior and passes. **Partial**
means some of it is verified and the gap is named. **Untested** and **Not started** mean what they say.

Test environment: the development container (Linux, headless Chromium 141 via Playwright 1.56). End-to-end tests run
on two Playwright projects: **desktop** (1440×900) and **phone** (Pixel 7 emulation, touch). No real phones, tablets,
Safari, or Firefox have been tested yet.

Run everything with `npm test` (70 unit tests) and `npm run test:e2e` (50 end-to-end runs: 25 tests × 2 projects).
